Строгий режим (strict)

Строгий режим — это «строгий инструктор» компилятора. Можно ехать без ремней безопасности: машина поедет, но авария будет дорогой. А можно пристегнуть все ремни разом одним движением — это и есть strict. Одна настройка "strict": true включает целый пакет проверок, которые ловят самые частые и болезненные ошибки — обращение к null, забытые типы, незаполненные поля — ещё в редакторе, до запуска, а не у пользователя в браузере. Разберём, что именно она включает и почему её держат включённой почти всегда.

Для нового проекта держите весь пакет включённым: это не «придирки компилятора», а бесплатный автопилот, который ловит ошибки за вас. Выключать что-то оправдано в основном при постепенном переводе большого старого проекта на строгие правила.

Коротко

  • strict — это рубильник, который одним махом включает целый пакет проверок (не одну).
  • Смысл: ловить ошибки рано и дёшево (в редакторе), а не поздно и дорого (в рантайме у пользователя).
  • Включён по умолчанию в TypeScript 6.0+. Раньше был выключен — отсюда старые советы «не забудьте включить».
  • Главные проверки: noImplicitAny (нет молчаливого any), strictNullChecks (обрабатывай null/undefined), strictPropertyInitialization (заполняй поля класса).
  • Ослаблять отдельные проверки можно ("strict": true + нужную в false), но для нового кода это не рекомендуется.
