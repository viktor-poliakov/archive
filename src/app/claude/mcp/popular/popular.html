Полезные серверы

Серверы, которые чаще всего подключают разработчики, и команды для Claude Code. Удалённые серверы просят войти: после добавления откройте /mcp и пройдите вход в браузере. В приложении Claude почти все эти сервисы есть в каталоге коннекторов: Customize → Connectors. Как устроено подключение — на странице Подключение сервера.

Код и задачи

Серверы проекта удобно ставить с --scope project: они попадут в .mcp.json и появятся у всей команды. У Linear есть и адрес только на чтение: https://mcp.linear.app/mcp/readonly.

Браузер и фронтенд

  • Playwright работает со структурой страницы, а не со скриншотами: быстро и без распознавания картинок. Подходит для сквозной проверки после правок.
  • Chrome DevTools — когда нужно понять, почему медленно или что падает в консоли и сети.
  • Личные инструменты вроде этих удобно ставить с --scope user — они будут во всех проектах.

Документация библиотек

Context7 подтягивает актуальную документацию нужной версии библиотеки. Модель знает API на дату обучения, а библиотеки обновляются чаще.

Работает без ключа, с бесплатным ключом лимиты выше: --header "Authorization: Bearer …".

Данные и сервисы

Базу подключайте пользователем только на чтение. Claude пишет SQL сам, и одна неудачная команда в рабочей базе может стоить дороже, чем вся экономия времени.

Что ставить не нужно

  • Файлы, git, загрузка веб-страниц — в Claude Code это есть и так: он читает и правит файлы, запускает команды в терминале, ищет в интернете.
  • Сервис с консольной утилитой (gh, stripe, vercel) — Claude Code умеет пользоваться ею через терминал. Сервер нужен, если утилиты нет или если тот же сервис нужен в приложении Claude.
  • Всё подряд «на всякий случай» — каждый сервер это процесс и права. Держите включёнными те, которыми пользуетесь.

Где искать ещё

  • Каталог Anthropic — claude.com/connectors: больше тысячи коннекторов и плагинов.
  • Маркетплейс плагинов — /plugin → Discover. Многие сервисы публикуют плагин: сервер и скиллы к нему ставятся вместе.
  • Официальный реестр MCP — registry.modelcontextprotocol.io.
  • Документация самого сервиса — ищите страницу «MCP»: там адрес сервера и команда для Claude Code.

Ставьте серверы от самого сервиса или из каталога Anthropic. Сторонние серверы никто не проверяет, а работают они с вашими правами.
