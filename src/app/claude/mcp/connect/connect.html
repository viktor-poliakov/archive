Подключение сервера

В приложении Claude MCP-сервер подключают кликами как коннектор, в Claude Code — командой claude mcp add или файлом .mcp.json, в API и Agent SDK — параметром запроса. Адрес сервера или команду запуска берут из документации сервиса. Что такое MCP и чем локальный сервер отличается от удалённого — на странице Что такое MCP.

В приложении Claude

  • Из каталога — Customize → Connectors → выберите сервис → Connect → войдите в его аккаунт.
  • Свой удалённый сервер — Customize → Connectors → Add → Custom → Web: имя и URL. Сервер должен быть доступен из интернета.
  • Локальный сервер — только в Claude Desktop: Settings → Extensions, расширение из каталога или из файла .mcpb.

Подробнее, с тарифами и настройками для команды, — на странице Коннекторы.

Сервер с OAuth сначала покажет статус Needs authentication: откройте /mcp, выберите его и войдите в браузере. Токен сохранится, повторно входить не нужно.

В Claude Code: локальный сервер

  • -- обязателен — он отделяет флаги Claude Code от команды сервера. Без него флаг вроде --dsn Claude Code примет за свой.
  • Имя сервера не ставьте сразу после --env — CLI примет его за ещё одну пару KEY=value. Поставьте между ними другой флаг, как в примере.
  • Базу данных подключайте пользователем только на чтение.

Для кого подключён: scope

ОбластьДля когоГде хранится
local (по умолчанию)Вы, только в этом проекте~/.claude.json
projectВсе, кто работает в репозитории.mcp.json в корне проекта, коммитится в git
userВы, во всех проектах~/.claude.json

Файл .mcp.json можно написать и руками. Секреты в него не кладут: ${VAR} подставит переменную окружения, ${VAR:-значение} — значение по умолчанию.

Серверы из .mcp.json Claude Code при первом запуске показывает и спрашивает, включать ли их: чужой репозиторий не подключит сервер молча. Сбросить ответы — claude mcp reset-project-choices. В headless-режиме (claude -p) вопроса нет, серверы загружаются сразу.

Проверка и управление

  • /mcp внутри сессии — статус каждого сервера (Connected, Needs authentication, Failed to connect), число инструментов, повторный вход, выключение для проекта.
  • Коннекторы из claude.ai появляются в Claude Code сами, если вы вошли подпиской: в /mcp они видны как claude.ai Gmail и т. п.
  • add-json — когда сервис даёт готовый JSON-конфиг: вставьте его как есть.

Как пользоваться

  • Просто опишите задачу — Claude сам найдёт подходящий инструмент среди подключённых.
  • Разрешения — перед первым вызовом инструмента Claude Code спросит разрешение. Чтобы не спрашивал, добавьте правило вроде mcp__sentry__* в allow (см. Разрешения и режимы).
  • Большие ответы — результат длиннее 50 000 символов Claude Code не вставляет в разговор, а сохраняет в файл и даёт Claude путь к нему.

В Claude API

MCP connector (бета): API сам подключается к серверу, писать MCP-клиент не нужно. Только удалённые серверы и только их инструменты.
