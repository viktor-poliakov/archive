Свой MCP-сервер

Свой сервер пишут, когда Claude нужен доступ к тому, для чего готового сервера нет: внутреннему API, своей базе, служебному скрипту. Это небольшая программа: вы описываете инструменты, а SDK берёт на себя протокол. Один и тот же сервер работает в Claude Code, Claude Desktop и других ИИ-клиентах. Подробный разбор с безопасностью и тестами — в разделе Агенты, tool use, MCP.

Нужен ли сервер

  • Только для себя в Claude Code, и есть скрипт или CLI — сервер не нужен. Опишите команду в скилле, и Claude запустит её через терминал.
  • Инструмент для своего агента на Agent SDK — проще createSdkMcpServer: сервер живёт прямо в вашем процессе.
  • Нужно в разных клиентах, всей команде, в приложении Claude или через API — пишите MCP-сервер.

Минимальный сервер

Пример на TypeScript: один инструмент, который отдаёт курс валюты ЦБ РФ. Сначала проект:

  • description пишется для модели — по нему Claude решает, когда звать инструмент. Укажите, для чего он и в каком виде аргументы.
  • inputSchema — схема Zod в z.object(…). SDK переведёт её в JSON Schema для модели и проверит аргументы до вызова обработчика.
  • Ошибка — ответ с isError: true, а не исключение. Модель увидит текст и поправит запрос.
  • stdout занят протоколом — console.log сломает обмен. Логи пишите через console.error.
  • Ключи и токены берите из process.env, а при подключении передавайте через --env.

Node.js 22.18 и новее запускает .ts без сборки. Официальные SDK есть и для Python, Go, Java, C#, Rust и других языков, устроены они так же: имя, описание, схема, обработчик.

Проверить сервер без Claude можно в MCP Inspector. Он откроет в браузере панель, где видно список инструментов и их можно вызвать с любыми аргументами:

Поменяли код — переподключите сервер в /mcp или перезапустите сессию: Claude Code держит запущенный процесс.

Удалённый сервер (HTTP)

Нужен, чтобы сервер работал в приложении Claude как свой коннектор, через API или у команды без установки. Инструменты те же, меняется только запуск:

Перед выкладкой в интернет добавьте HTTPS, авторизацию (OAuth или токен в заголовке) и проверку заголовков Host и Origin. Сам обработчик ничего этого не делает, в SDK для этого есть готовые функции.

Как раздать

  • Команде в репозитории — запись в .mcp.json (область project, см. Подключение сервера).
  • Плагином — файл .mcp.json в корне плагина, пути через ${CLAUDE_PLUGIN_ROOT}. Вместе с сервером можно отдать скиллы о том, как им пользоваться (Свой плагин).
  • В приложение Claude — удалённый сервер добавляют как свой коннектор: Customize → Connectors → Add → Custom → Web. Локальный упаковывают в расширение .mcpb для Claude Desktop: npx @anthropic-ai/mcpb init, затем pack.
  • Всем — опубликуйте пакет в npm и зарегистрируйте сервер в официальном реестре MCP.
