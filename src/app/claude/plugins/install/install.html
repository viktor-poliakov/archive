Claude/Плагины/Установка

Установка

Плагин ставят из каталога (маркетплейса) или из папки на диске. В приложении Claude — на странице Customize → Plugins, в Claude Code — командой /plugin. Плагин из приложения сам появляется в Claude Code, обратно — нет. Что такое плагин и что в нём лежит — на странице Что такое плагин.

В приложении Claude

  • 1. Откройте Customize → Plugins в claude.ai или десктоп-приложении.
  • 2. Discover → выберите плагин → Add. Каталог Anthropic там есть на Pro, Max, Team и Enterprise.
  • 3. Свой источник — Add → Add marketplace (репозиторий GitHub: URL или owner/repo) или Add → Upload plugin (архив .zip или .plugin).
  • Коннекторы подключают отдельно. Установка плагина ничего не подключает и ни в какой сервис вас не авторизует: откройте плагин → вкладка Connectors → подключите каждый. Скиллы работают и без этого, но до сервиса не достанут.
  • Вызов — опишите задачу, Claude возьмёт подходящий скилл сам. Или наберите /: в меню скиллы подписаны именем плагина. В Cowork команду плагина вызывают как /plugin-name:command.
  • Выключить — переключатель Disable plugin в карточке, удалить — меню плагина → Remove. Обновления из каталога приходят сами.
  • Плагин привязан к аккаунту — он есть в чате (веб, десктоп, мобильные), в Cowork и в Claude Code: там он появится как <имя>@synced при следующем запуске.
  • Team и Enterprise — владелец может поставить плагин всем: по умолчанию (участник может выключить) или обязательно (выключить нельзя).

В Claude Code

Официальный маркетплейс claude-plugins-official Claude Code добавляет сам при первом запуске, так что ставить из него можно сразу:

При установке Claude Code спрашивает, для кого включить плагин:

ОбластьДля когоКуда записывается
userВы, во всех проектах~/.claude/settings.json
projectВсе, кто работает в репозитории.claude/settings.json, коммитится в git
localВы, только в этом репозитории.claude/settings.local.json
  • Область project плагин включает, но не скачивает: каждый участник один раз ставит его у себя — claude plugin install … --scope project.
  • Десктоп-приложение (вкладка Code) — кнопка + у поля ввода → Add plugins. VS Code — /plugins. Плагин в области user виден везде на этом компьютере: файлы настроек у терминала, десктопа и VS Code общие.
  • Облачные сессии (claude.ai/code) локальные плагины не загружают.

Пример: проверка типов для TypeScript

Теперь после каждой правки .ts-файла Claude видит ошибки типов и пропущенные импорты, не запуская сборку. В разговоре это строка Found N new diagnostic issues, подробности — по Ctrl+O. Если сервер не установлен, на вкладке Errors в /plugin будет Executable not found in $PATH. Для других языков — pyright-lsp, gopls-lsp, rust-analyzer-lsp и т. д.

Управление

  • /plugin → Installed — Space включает и выключает плагин, Enter открывает карточку: Update now, Uninstall. Давно не использованные собраны в группе Not used recently.
  • /reload-plugins — применить изменения без перезапуска сессии.
  • Автообновление включено для официальных маркетплейсов Anthropic, для сторонних выключено. Переключается на вкладке Marketplaces.
  • Выключенный плагин остаётся на диске, но не занимает контекст и ничего не запускает.
