Что такое плагин

Плагин — папка, в которой вместе лежат скиллы, субагенты, хуки и MCP-серверы. Ставится, обновляется и выключается целиком, одной командой. Так чужую готовую настройку получают за минуту, а свою раздают команде. Формат один для приложения Claude (чат и Cowork) и для Claude Code.

Зачем нужны

ПлагинЧто даёт
commit-commandsКоманды Claude Code для коммита, пуша и pull request: /commit-commands:commit
typescript-lsp, pyright-lsp и другие *-lspClaude видит ошибки типов сразу после своей правки, без запуска сборки, и ищет определения по символам, а не по тексту
Плагины сервисовMCP-сервер сервиса и скиллы о том, как с ним работать. Большую часть официального каталога публикуют сами вендоры
sales, legal, finance и др.Не про код: подготовка к звонку, разбор договора, сверка счетов. Для приложения и Cowork, из набора knowledge-work-plugins
Плагин вашей командыОдинаковые скиллы, агенты и хуки у всех. В Claude Code включается для всего репозитория, на Team и Enterprise владелец делает плагин обязательным

Из чего состоит

  • plugin.json — манифест. Обязательно в нём только name, а без манифеста плагин тоже загрузится: компоненты найдутся по папкам.
  • Имена с префиксом — скилл из skills/review/ вызывается как /my-plugin:review. Поэтому плагины не конфликтуют ни друг с другом, ни с вашими скиллами.
  • Всё необязательно — плагин может состоять из одного скилла или одного MCP-сервера.

Где что работает

Каждое приложение загружает из плагина то, что умеет, остальное пропускает. Поэтому в Cowork и Claude Code плагин может больше, чем в чате:

КомпонентЧатCoworkClaude Code
Скиллы и командыДа, команда работает как скиллДаДа
MCP-серверыУдалённые, после подключения на вкладке ConnectorsДа, локальные — если сессия идёт на вашем компьютереДа
Субагенты и хукиНетДаДа
LSP-серверы, стили ответов, темыНетНетДа

Плагин с папкой bin/ (свои утилиты в PATH) приложение и Cowork не установят вовсе — такой работает только в Claude Code.

Плагин или отдельные файлы

  • Для себя плагин не нужен: скилл, субагент, хук и MCP-сервер работают и сами по себе. Положили скилл в ~/.claude/skills/ — и он есть во всех проектах.
  • Чтобы раздать — плагин: команде, на много проектов или машин, с версиями и обновлениями из маркетплейса.

Чего стоит включённый плагин

  • Контекст — имена и описания всех его скиллов и агентов лежат в контексте каждый ход, даже если плагин сейчас не нужен. Полный текст подгружается только при вызове. Лишние плагины лучше выключать.
  • Процессы — его MCP-серверы запущены, а хуки срабатывают в каждой сессии, а не только когда вы им пользуетесь.
  • Права — всё, что плагин запускает, запускается от вашего имени.

Проверены только плагины из каталога Anthropic: каждая версия проходит автоматический скан, а новый плагин перед публикацией смотрит человек. Сторонние маркетплейсы, загрузку архивом и папки с диска никто не проверяет — ставьте их только из надёжных источников. Как установить плагин — на странице Установка.
