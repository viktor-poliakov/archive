Что такое агент

Агент — модель, которая решает задачу сама, в несколько шагов: выбирает действие, выполняет его через инструмент, смотрит на результат и решает, что делать дальше. Обычный чат отвечает текстом за один ход, а агент работает, пока задача не решена. Claude Code — агент для разработки; свои агенты есть и в приложении Claude, и в API.

Из чего состоит

  • Модель — думает: понимает задачу, разбивает её на шаги, выбирает следующий.
  • Инструменты (tools) — действуют: читают и правят файлы, запускают команды, ищут в интернете, работают с сервисами через MCP. Без них модель может только писать текст.
  • Обвязка (harness) — программа вокруг модели: даёт ей инструменты, выполняет их вызовы, следит за контекстом и разрешениями. Claude Code и есть такая обвязка.

Как это устроено на уровне API — вызов инструментов, цикл в коде, ограничители, MCP — разобрано без привязки к Claude на странице Агенты, tool use, MCP.

Агентный цикл

Агент работает по кругу: собирает контекст → действует → проверяет результат. Сколько будет кругов, модель решает по ходу дела. Например, Claude Code на просьбу «почини падающие тесты»:

ШагЧто делаетИнструмент
1Запускает тесты и смотрит, что упалоBash
2Ищет файлы, связанные с ошибкойGrep, Glob
3Читает ихRead
4Исправляет кодEdit
5Снова запускает тесты. Если что-то падает — возвращается к шагу 2Bash

Вопросу о коде хватит одного сбора контекста, а большой рефакторинг займёт десятки кругов.

Как ставить задачу агенту

Как коллеге: цель, где смотреть и как понять, что готово. Какие файлы читать и какие команды запускать, агент решит сам.

  • Критерий готовности — тесты, сборка, скриншот. Агенту есть чем себя проверить, и он не остановится на полпути.
  • Крупную задачу сначала обсудите в Plan mode: поправить план дешевле, чем переделывать код.

Как держать агента под контролем

Агент работает сам, но вмешаться можно в любой момент. В Claude Code:

ДействиеЧто произойдёт
EscОстановить сразу. Текущий вызов инструмента отменяется
Текст + Enter во время работыПоправка без остановки: Claude прочитает её после текущего шага и учтёт
Esc EscОткатить файлы к одной из прошлых точек (checkpoint)
Shift+TabСменить режим разрешений: спрашивать перед каждой правкой или нет

Чекпоинты возвращают только файлы. Запись в базу, деплой или отправленное сообщение не откатить — такие действия ограничивают разрешениями.
