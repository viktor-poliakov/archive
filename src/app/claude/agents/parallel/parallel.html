Параллельные сессии

Несколько сессий Claude Code одновременно, у каждой своя задача: одна пишет фичу, вторая чинит баг, третья гоняет миграцию. В отличие от субагентов, ими управляете вы, а не Claude. Главное правило — сессии не должны править одни и те же файлы, для этого есть worktree.

Worktree: своя копия файлов

Git worktree — отдельная папка с отдельной веткой, но общей историей репозитория. Каждая сессия правит свою копию, и правки не перемешиваются.

  • Где — .claude/worktrees/<имя>/, ветка worktree-<имя>. Добавьте .claude/worktrees/ в .gitignore.
  • От чего ветвится — от основной ветки на удалённом репозитории. Чтобы начать от текущей работы, задайте "worktree": { "baseRef": "head" } в settings.json.
  • Это чистая копия — зависимости ставятся заново, а файлов из .gitignore в ней нет. Чтобы .env и секреты копировались сами, перечислите их в .worktreeinclude в корне проекта:
  • При выходе пустой worktree удаляется сам. Если в нём есть правки, Claude спросит, оставить ли его.
  • Внутри сессии достаточно попросить «работай в worktree» — Claude создаст его сам.

Фоновые сессии

Сессию можно запустить в фоне и не держать для неё терминал. Все фоновые сессии видны на одном экране — agent view (research preview, интерфейс ещё меняется).

  • Статусы — работает, ждёт вас (жёлтый: вопрос или разрешение), свободна, готово (зелёный), ошибка (красный).
  • Space — подсмотреть сессию и ответить, не выходя из списка. Enter — открыть весь разговор. ← в пустом поле — вернуться к списку; сессия при этом продолжает работать.
  • Файлы — запущенная из agent view сессия перед первой правкой сама переходит в свой worktree.

В десктопе и в облаке

  • Десктоп — новая сессия: + New или Ctrl+N (Cmd+N на macOS). Две рядом — Alt+клик (Option на macOS) по сессии в боковой панели или правый клик → Open in → Split view. Свой worktree включается переключателем Worktree под полем ввода до старта сессии.
  • Облако — сессия работает на серверах Anthropic, даже когда ноутбук закрыт. Следить за ней можно на claude.ai/code или в мобильном приложении. Облако клонирует ветку с GitHub, а не вашу локальную папку, поэтому сначала сделайте push. Доступно на Pro, Max, Team и Enterprise.

Когда сессиям нужно договориться

Сессии на одной машине могут писать друг другу. Попросите Claude передать находку соседу или упомяните сессию через @имя:

  • /list-agents — с кем сессия может связаться.
  • Сообщение от сессии — не ваше слово: оно не одобряет разрешения и не меняет настройки, все запросы прав по-прежнему приходят вам.
  • Agent teams — следующий шаг: ведущая сессия сама делит работу между «напарниками», у них общий список задач и переписка. Это экспериментальная функция, она выключена по умолчанию и тратит заметно больше токенов. Включается так:

Напарники в команде не получают отдельных worktree — делите работу так, чтобы каждый правил свои файлы. А чтобы разложить одну большую правку на 5–30 субагентов, каждый в своём worktree, есть встроенный скилл /batch.
