Безопасность

Claude Code выполняет команды и правит файлы с вашими правами, а в приложении действует в ваших сервисах и в браузере. Защита строится слоями: разрешения решают, что можно без вопроса, песочница ограничивает команды на уровне ОС, а вы проверяете результат. Что вообще можно отправлять нейросети — в статье «Что отдавать нейросети, а что нет».

Главные риски

РискПримерЗащита
Разрушительная командаrm -rf, git push --force, миграция на продеРежим auto или ручной, ask на push, deny на опасное
Утечка секретовClaude прочитал .env, и ключ попал в лог или коммитDeny на чтение секретов, песочница

Разрешения

  • Режим — auto (действия проверяет модель-классификатор) или ручной. bypassPermissions — только в контейнере или виртуальной машине.
  • Deny на секреты, ask на push — пример правил и их синтаксис в Разрешениях и режимах.
  • Правила сравниваются с текстом команды — deny на чтение .env не помешает скрипту открыть файл. Для гарантий нужна песочница.
  • /permissions — время от времени проверяйте, что уже разрешено «навсегда».

Песочница

/sandbox включает изоляцию команд на уровне ОС: писать можно только в рабочую папку, а в сеть — только на разрешённые домены. Внутри этих границ команды выполняются без вопросов, а prompt injection не сможет увести данные наружу.

  • Чтение по умолчанию открыто почти везде, включая ~/.ssh и ~/.aws/credentials. Закройте их в credentials, как в примере: встроенного списка нет.
  • Только команды — встроенные инструменты чтения и правки, MCP-серверы и хуки работают вне песочницы, по правилам разрешений.
  • Платформы — macOS, Linux и WSL2. В обычной Windows команды идут без песочницы — запускайте Claude Code в WSL2.
  • Полная изоляция — весь Claude Code в dev-контейнере или виртуальной машине. Нужна для bypassPermissions и чужого кода.

Чужой код и расширения

  • Диалог доверия — при первом запуске в незнакомой папке Claude Code спросит, доверяете ли вы ей. Серверы из проектного .mcp.json подтверждаются отдельно. claude -p не показывает ни того, ни другого — не запускайте его в непроверенном репозитории.
  • MCP-серверы и плагины — только от доверенных авторов. Anthropic проверяет коннекторы из каталога на соответствие требованиям, но аудит безопасности MCP-серверов не проводит.
  • Хук — это команда на вашей машине, с вашими правами и вне песочницы. Читайте хуки в чужом .claude/settings.json.
  • Код от Claude — смотрите дифф, а перед PR запустите /security-review.

В приложении Claude

  • Коннекторы — у Claude в сервисе ваши права. Подключайте только нужное, а для записи и удаления оставьте подтверждение.
  • Claude in Chrome — страница может содержать скрытые инструкции. На сайтах с деньгами и личными данными не оставляйте его без присмотра, «всегда разрешать» давайте только доверенным сайтам.
  • Обучение на ваших чатах — на Free, Pro и Max это решает переключатель в Settings → Privacy.

В Claude API

  • Ключ — только на сервере, в переменной окружения или хранилище секретов. Не в коде, не в репозитории и не во фронтенде. Утёк — сразу отзовите его в Console.
  • Лимит трат на workspace в Console: утёкший ключ не опустошит счёт.
  • Модель предлагает — код решает. Аргументы инструментов проверяйте, как пользовательский ввод, а необратимые действия — только с подтверждением человека.
