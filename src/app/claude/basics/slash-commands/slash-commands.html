Слэш-команды

Слэш-команда — сообщение, которое начинается с /. Встроенные команды управляют самой сессией — моделью, контекстом, разрешениями, — а свои команды и скиллы подставляют заранее написанный промпт. Наберите / в поле ввода — появится меню всех доступных команд, дальше можно фильтровать по буквам.

Как вызывать

Команда распознаётся только в начале сообщения. Всё, что написано после её имени, — аргументы:

  • Во время ответа — команда встанет в очередь и выполнится, когда Claude закончит. Некоторые, например /status и /usage, срабатывают сразу.
  • Не у всех одинаково — набор команд зависит от платформы, тарифа и подключённых плагинов. Точный список — в меню по / или в /help.

/clear или /compact? Начинаете другую задачу — /clear: старая переписка только мешает. Продолжаете ту же, но контекст забит — /compact: Claude сожмёт историю и продолжит с краткого изложения. Подробнее — в Контексте и компактизации.

Свои команды

Своя команда — markdown-файл с промптом. Файл .claude/commands/fix-tests.md в проекте создаёт команду /fix-tests:

Вызов — имя файла и аргументы:

  • $ARGUMENTS — всё, что написано после команды. Отдельные аргументы — $0, $1… (счёт с нуля).
  • !`команда` — выполняется до отправки, и Claude получает уже её вывод, а не саму команду.
  • Шапка — description показывается в меню, argument-hint — подсказка к аргументам, model — модель для этой команды, allowed-tools — инструменты, которые можно без вопросов.
  • Подпапки — .claude/commands/db/migrate.md превращается в /db:migrate.
  • Для всей команды — закоммитьте .claude/commands/, и команды появятся у всех, кто клонирует репозиторий.

Команды теперь — часть скиллов. Файл .claude/skills/fix-tests/SKILL.md создаёт ту же /fix-tests, но рядом можно положить скрипты и шаблоны, а Claude умеет вызывать скилл сам, когда задача подходит. Личные команды для всех проектов кладут в ~/.claude/skills/. Старые файлы в .claude/commands/ продолжают работать. Подробнее — в Своём скилле.
