Что такое скилл

Скилл (Agent Skill) — папка с файлом SKILL.md: инструкция, как делать определённую задачу, и при необходимости скрипты, шаблоны и справочники к ней. Claude держит в голове только имя и описание каждого скилла, а саму инструкцию читает, когда задача подходит. Написали один раз — и больше не объясняете то же самое в каждом чате. Скиллы работают в приложении Claude, в Claude Code и через API. Формат открытый (agentskills.io), его понимают и другие агенты.

Зачем нужны

ЗадачаЧто даёт скилл
Презентации и документы по брендбукуЦвета, шрифты и шаблон лежат в скилле — не нужно прикладывать их к каждому запросу
Word, Excel, PowerPoint, PDFГотовые скиллы Anthropic: таблицы с формулами и графиками, вёрстка документов, заполнение PDF-форм
Отчёт или письмо по шаблону компанииОдинаковая структура каждый раз. Вместе с коннекторами скилл знает, откуда брать данные
Порядок работы в проектеРелиз, миграция, ревью по чек-листу команды — шаги и команды в одном файле, вызов через /release в Claude Code
Повторяемые операцииПроверку или преобразование делает скрипт из скилла — надёжнее и дешевле, чем каждый раз генерировать код заново

Как устроен

Обязателен только SKILL.md, остальное — по желанию. Справочники Claude читает, когда на них ссылается инструкция, а скрипты запускает:

Вверху SKILL.md — frontmatter с именем и описанием, ниже — сама инструкция:

  • name — латиница в нижнем регистре, цифры и дефисы, до 64 символов. В Claude Code без него скилл называется по папке.
  • description — что делает скилл и когда его брать. Главное поле: по нему Claude решает, нужен ли скилл для запроса.

Как Claude его загружает

Скилл читается по частям, поэтому их можно поставить десятки — контекст это почти не занимает:

ЧтоКогда попадает в контекстСколько стоит
name и descriptionВсегда, с начала сессииОколо 100 токенов на скилл
Тело SKILL.mdКогда запрос подошёл под описание или скилл вызвали вручнуюРекомендуют держать в пределах 5 тыс. токенов
Остальные файлыТолько если инструкция на них сослалась и они понадобилисьСправочник — по размеру файла. У скрипта — только его вывод, сам код в контекст не попадает

Скилл или что-то другое

ИнструментЧем отличается от скилла
CLAUDE.md, проекты, личные инструкцииЛежат в контексте всегда — для общих правил. Скилл подгружается только под свою задачу
MCP и коннекторыДают доступ к сервисам и данным. Скилл объясняет, что с ними делать. Работают вместе
СубагентРаботает в отдельном контексте и возвращает отчёт. Скилл — в основном разговоре
Слэш-командаВ Claude Code свои команды стали частью скиллов: скилл тоже вызывается через /имя, но может сработать и сам
ПлагинУпаковка для распространения: внутри могут быть скиллы, субагенты, хуки и MCP-серверы

Какие бывают

  • От Anthropic — docx, xlsx, pptx, pdf для документов. В приложении и API работают без настройки, Claude берёт их сам, когда создаёт файлы. В Claude Code свой набор встроенных скиллов: /code-review, /simplify, /loop, /claude-api и другие.
  • Партнёрские — от Notion, Figma, Atlassian и других, обычно в паре с их коннектором. Лежат в каталоге скиллов приложения.
  • Свои — пишете сами или просите Claude написать. Как — в Своём скилле.
  • Организации — на Team и Enterprise владелец раздаёт скиллы всем участникам.

Скилл — это код и инструкции, которые Claude выполнит. Чужой скилл может велеть Claude отправить ваши данные наружу или запустить что-то лишнее. Ставьте скиллы только из надёжных источников, а незнакомые сначала прочитайте целиком, вместе со скриптами. Как подключить и вызвать скилл — в Подключении и вызове.
