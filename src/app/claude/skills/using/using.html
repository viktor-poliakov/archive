Подключение и вызов

Чтобы скилл заработал, его достаточно положить туда, где Claude его увидит: включить в настройках приложения, скопировать папку для Claude Code или передать в запросе к API. Дальше Claude сам берёт скилл, когда запрос подходит под описание. Вызвать вручную тоже можно — по имени. Что такое скилл и из чего он состоит — на странице Что такое скилл.

В приложении Claude

  • 1. Settings → Capabilities → включите Cloud code execution and file creation. Скиллы работают в той же песочнице, что и создание файлов, без неё они не запустятся.
  • 2. Customize → Skills — здесь включают и выключают скиллы. Скиллы Anthropic для Word, Excel, PowerPoint и PDF уже работают.
  • 3. Новый скилл — кнопка +: Browse skills открывает каталог (готовые и партнёрские), Create skill → Upload a skill загружает свой.

Свой скилл загружают ZIP-архивом папки, внутри которой лежит SKILL.md. Имя папки должно совпадать с полем name, иначе загрузка не пройдёт. Загружать свои скиллы можно на всех тарифах, включая Free.

  • Вызов — обычно никакой: Claude сам выбирает скилл по запросу. Не сработал — назовите прямо: «Используй скилл brand-guidelines и сделай презентацию».
  • Team и Enterprise — сначала владелец включает скиллы: Organization settings → Plugins & skills → Policy. Он же может раздать скиллы всем участникам или запретить загружать свои.
  • Поделиться — на Team и Enterprise: в Customize → Skills меню ⋯ у скилла → Share, коллега получит копию только для чтения. Publish to org отправляет скилл в библиотеку организации (иногда через проверку владельцем). На Free, Pro и Max скилл есть только у вас.

В Claude Code

Скилл — это просто папка на диске. Claude Code ищет их в нескольких местах:

Где лежитДля кого
~/.claude/skills/<name>/SKILL.mdВы, во всех проектах
.claude/skills/<name>/SKILL.mdТекущий проект. Кладут в git — скилл есть у всей команды
Папка skills/ плагинаВезде, где включён плагин. Имя с префиксом: /плагин:скилл
~/.claude/skills/synced/Скиллы, включённые в приложении Claude. Скачиваются сами, если вы вошли аккаунтом claude.ai, а не API-ключом

Чужой скилл ставят двумя способами: скопировать его папку в .claude/skills/ или ~/.claude/skills/ либо установить плагин. Например, скиллы Anthropic для документов:

Вызов — сам по описанию или вручную через /:

  • Совпали имена — личный скилл побеждает проектный, а скилл заменяет одноимённую команду из .claude/commands/. Скиллы плагинов не конфликтуют: у них префикс.
  • Правки подхватываются сразу, без перезапуска. Если папки skills до старта сессии не было, один раз выполните /reload-skills.
  • Скилл из приложения не правят локально: при следующей синхронизации правка пропадёт. Меняйте его в приложении.

Кто может вызвать скилл

По умолчанию — и вы, и Claude. Два поля во frontmatter это меняют:

ПолеЧто меняетКогда нужно
disable-model-invocation: trueТолько вручную, Claude сам не вызовет. Описание даже не попадает в контекстДействия с последствиями: деплой, рассылка, коммит
user-invocable: falseТолько Claude, в меню / скилла нетСправочные знания, которые вручную звать незачем

Выключить чужой скилл без правки файла — в /skills выберите его и нажмите Space: состояние запишется в skillOverrides в .claude/settings.local.json. Не давать Claude вызывать скилл — правило Skill(deploy *) в deny разрешений.

Через API

Скиллы передают в поле container, до 20 штук на запрос, вместе с инструментом code execution — без него скилл не запустится:

  • Скиллы Anthropic — type: 'anthropic' и короткое имя: pptx, xlsx, docx, pdf.
  • Свои сначала загружают — получится id вида skill_01…. Скилл виден всему workspace.
  • Готовые файлы приходят как file_id в результате code execution, скачивают их через Files API.
  • В песочнице API нет интернета, и пакеты в ней не установить — только то, что предустановлено.

Скиллы API отдельно от приложения. Из приложения в Claude Code скиллы скачиваются сами, а в API их нужно загрузить отдельно — и наоборот, загруженные через API в приложении не появятся.
