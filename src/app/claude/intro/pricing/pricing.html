Тарифы и лимиты

Платить за Claude можно двумя способами. Подписка — фиксированная сумма в месяц и лимит использования. API — оплата за каждый потраченный токен. Claude Code работает с обоими.

Цены указаны в долларах и без налогов. В некоторых странах их показывают в местной валюте, а налог либо уже входит в цену, либо добавляется при оплате.

Как устроены лимиты

  • Окно в 5 часов — лимит считается в скользящем пятичасовом окне. На платных тарифах сверху есть ещё недельный лимит.
  • Общий счёт — чат и Claude Code тратят один и тот же лимит.
  • Что тратит быстрее — длинные переписки, большие файлы, старшие модели, высокий effort, многошаговые задачи агентов.
  • Fable 5.1 — на Pro доступна только за usage credits, на Max и Team Premium на неё можно потратить до половины недельного лимита.
  • Лимит закончился — подождите сброса, перейдите на тариф выше или включите usage credits: доплату по ценам API с предоплатой и потолком трат.

Посмотреть расход: в Claude Code — командой ниже, на сайте — Settings → Usage.

API

Оплата за токены через Claude Console. Новым пользователям дают немного бесплатных кредитов, чтобы попробовать.

Fable 5.11050

  • Prompt caching — повторно отправленный кусок запроса читается из кэша за 2,5–10% обычной цены. Запись в кэш стоит в 1,25–2 раза дороже обычного входа.
  • Batch API — скидка 50%, если ответ может подождать.
  • Claude Code по API — по данным Anthropic, в среднем около $13 за активный день и $150–250 в месяц на разработчика.

Частая ловушка. Если в системе задана переменная ANTHROPIC_API_KEY, Claude Code использует её вместо подписки, и вы платите по API.

Что выбрать

  • Только посмотреть — Free, но без Claude Code.
  • Claude Code время от времени — Pro.
  • Claude Code — основной инструмент — Max: лимиты кончаются заметно реже.
  • Свой продукт или автоматизация — API.

Как тратить меньше лимитов — на странице Экономия токенов.
