Что такое Claude

Claude — семейство ИИ-моделей компании Anthropic. Одна и та же модель доступна в трёх продуктах: в чате, в агенте для разработки Claude Code и через API. Этот раздел в основном про Claude Code — как подключить и настроить его под свою работу.

Три продукта

ПродуктДля чегоГде взять
Claude (чат) Вопросы, тексты, разбор документов и картинок claude.ai, приложения для компьютера и телефона
Claude Code Агент для разработки: сам читает проект, правит файлы, запускает команды Терминал, IDE, десктоп, веб — см. где работает
Claude API Встроить модель в свой продукт Claude Console, оплата за токены — см. Messages API

Чат и Claude Code: в чём разница

В чате вы описываете задачу, получаете ответ и сами переносите код в проект. Claude Code работает прямо в проекте: открывает нужные файлы, вносит правки и проверяет результат.

ЧатClaude Code
Видит проектТолько то, что вставили или загрузилиВесь репозиторий
Меняет ваши файлыНет, вы копируете ответДа, сам
Запускает командыНетТесты, сборку, git — с вашего разрешения

Что такое агент в общем виде (цикл «подумал → вызвал инструмент → посмотрел результат») — на странице Агенты, tool use, MCP раздела «Экосистема».

Что нужно, чтобы начать

  • Чат — бесплатного аккаунта на claude.ai хватит, чтобы попробовать. Платные тарифы поднимают лимиты.
  • Claude Code — подписка Pro, Max, Team или Enterprise либо аккаунт Claude Console с оплатой по API. Бесплатный план Claude Code не включает. Компании могут подключать его через Amazon Bedrock, Google Cloud или Microsoft Foundry.
  • API — аккаунт в Claude Console и API-ключ, платите за израсходованные токены.

Подробнее о ценах и лимитах — на странице Тарифы и лимиты.

Модели

Claude — это не одна модель, а линейка. Старшие модели умнее, но медленнее и дороже, младшие — быстрые и дешёвые. В Claude Code модель переключается командой /model. Какую когда брать — на странице Модели и выбор.
