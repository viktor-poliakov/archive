CLI, десктоп, IDE, веб

Claude Code — один движок в нескольких оболочках. CLAUDE.md, настройки и MCP-серверы проекта работают везде одинаково, поэтому оболочку выбирают по удобству, а не по возможностям.

Терминал

Установка одной командой. Обновляется сам в фоне, Node.js не нужен.

Дальше заходите в папку проекта и запускаете:

  • Система — macOS 13+, Windows 10 (1809) и новее, Ubuntu 20.04+, Debian 10+; от 4 ГБ памяти.
  • Windows — желательно поставить Git for Windows, тогда Claude сможет пользоваться bash. Без него работает через PowerShell.
  • Другие способы — brew install --cask claude-code, winget install Anthropic.ClaudeCode или npm (нужен Node.js 22+). Сами они не обновляются.

Десктоп

Скачайте приложение Claude, откройте вкладку Code и выберите папку проекта. Терминал не нужен, но нужна платная подписка. Настройки приложение берёт из тех же файлов, что и CLI.

IDE

  • VS Code (1.94+) — в панели Extensions найдите «Claude Code» от Anthropic и нажмите Install. В Cursor ставится так же.
  • JetBrains — сначала установите CLI (см. выше), затем плагин «Claude Code» из JetBrains Marketplace и перезапустите IDE.

Нюанс. Расширение VS Code носит свою копию Claude Code внутри. Чтобы команда claude работала и в обычном терминале, CLI ставят отдельно.

Веб и телефон

Откройте claude.ai/code, подключите GitHub, выберите репозиторий и опишите задачу. Claude сам клонирует код в облачную машину, работает там и может открыть pull request. Ход работы виден и с телефона — во вкладке Code приложения Claude.

Что выбрать

  • Только начинаете — десктоп или расширение для VS Code: правки видны наглядно, команды запоминать не нужно.
  • Автоматизация и CI — терминал, см. Headless-режим.
  • Долгие задачи, не занимающие ваш компьютер — веб.
