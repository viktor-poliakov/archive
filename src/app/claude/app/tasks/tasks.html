Задачи и расписание

Задача (task) — работа, которую Claude выполняет сам, а не просто отвечает на сообщение: планирует шаги, работает с файлами, сайтами и сервисами и отдаёт готовый результат. Раньше для этого был отдельный режим Cowork, в новом интерфейсе он слился с обычным чатом. Задачу можно поставить на расписание, и Claude будет повторять её сам.

Для чего

  • Работа с файлами — разобрать папку, собрать отчёт из сканов, привести таблицы к одному виду.
  • Документы из материалов — отчёт по расшифровкам встреч, презентация из заметок, таблица с формулами.
  • Длинные цепочки шагов — найти, сравнить, свести, оформить. Claude сам делит работу на подзадачи и может вести несколько параллельно.
  • Регулярная рутина — утренние сводки, еженедельные отчёты, мониторинг новостей. Для неё есть расписание.

Как поставить задачу

  • 1. Откройте Claude в браузере, Claude Desktop или на телефоне. Если в поле ввода есть переключатель Chat / Cowork, выберите Cowork. В новом интерфейсе его нет: Claude сам решает, хватит ли ответа или нужна задача.
  • 2. Опишите задачу. Если нужны файлы с компьютера, подключите папку: Claude читает и пишет только в подключённых папках.
  • 3. Проверьте план и запускайте. По ходу работы можно уточнять и менять направление, в том числе с другого устройства.
  • 4. Готовые файлы появятся в той же сессии: их можно посмотреть и скачать.

Подтверждения и ограничения

  • Manual — вы разрешаете или запрещаете каждое действие. В новом интерфейсе это режим по умолчанию.
  • Auto — Claude сам проверяет каждое действие и блокирует опасные. Быстрее, но тратит больше лимита.
  • Skip all approvals — без проверок. Только если полностью доверяете задаче и источникам.
  • Удаление файлов — перед безвозвратным удалением Claude всегда спрашивает разрешение.
  • Компьютер — к локальным файлам, браузеру и управлению компьютером Claude обращается через Claude Desktop (macOS, Windows), поэтому приложение должно быть открыто.
  • Тарифы и лимиты — Pro, Max, Team, Enterprise. Многошаговая задача расходует лимит заметно быстрее короткого вопроса.

Расписание

  • Создать в новом интерфейсе — напишите в чате, что и как часто делать, и ответьте на уточняющие вопросы. Проверьте название, расписание и инструкции и нажмите Schedule.
  • Создать в Cowork — слева Scheduled → New task. Дальше Create with Claude (настроить в диалоге) или Set up manually (заполнить имя, промпт, режим подтверждений, частоту, модель и папку).
  • Частота — каждый час, день, неделю, по будням или только вручную.
  • Где выполняется — в облаке, так что задача сработает, даже если компьютер спит, а Claude Desktop закрыт. Исключение — задачи, которым нужны локальные файлы или программы: они запускаются только на компьютере.
  • Управление — на странице Scheduled: прошлые и будущие запуски, правка, пауза, запуск вне расписания, удаление.
  • Что доступно — коннекторы, скиллы и плагины. Каждый запуск — отдельная сессия, результат смотрите в ней.

Другие расписания. В Claude in Chrome по расписанию запускаются ярлыки браузера. В Claude Code есть свои механизмы, /loop и облачные задачи /schedule, — см. Задачи по расписанию.
