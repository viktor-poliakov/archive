Claude in Chrome

Claude in Chrome — расширение для Google Chrome. С ним Claude сам работает в браузере: читает страницы, кликает, заполняет формы, переходит между вкладками. Общаетесь вы с ним в боковой панели рядом с сайтом.

Для чего

  • Разобраться во вкладках — сводка или сравнение открытых страниц.
  • Перенести данные — со страницы в документ, таблицу или форму.
  • Рутина в веб-сервисах — почта, календарь, документы, CRM. Работает и там, где нет коннектора: Claude действует через интерфейс сайта, как человек.
  • Повторяющиеся задачи — удачный запрос можно сохранить и запускать по расписанию.

Как установить

  • 1. Откройте Chrome Web Store, найдите расширение Claude и нажмите Add to Chrome.
  • 2. Войдите аккаунтом Claude и выдайте запрошенные разрешения.
  • 3. Закрепите расширение: значок пазла на панели → булавка рядом с Claude.
  • 4. Нажмите значок Claude — откроется боковая панель. Напишите задачу.

Нужен платный тариф: Pro, Max, Team или Enterprise. Поддерживается только Google Chrome на компьютере, боковая панель пока в бете. В Claude Desktop браузер подключается как коннектор: Settings → Connectors → Claude in Chrome → Configure.

Ярлыки и расписание

  • Ярлык (shortcut) — сохранённый запрос. В панели наберите / и выберите его. Править и удалять ярлыки можно в настройках расширения.
  • Расписание — значок часов вверху панели: ярлык запускается раз в день, неделю, месяц или год.

Режимы и безопасность

  • Automatically approve (по умолчанию) — Claude сам проверяет каждое действие и останавливается, когда нужно ваше подтверждение.
  • Manually approve — спрашивает перед каждым действием.
  • Skip all approvals — без вопросов. Только на доверенных сайтах и только пока вы смотрите.
  • Разрешения сайтов — Always allow actions on this site давайте только сайтам, которым полностью доверяете. Отозвать можно в настройках расширения, раздел Site Permissions.
  • Без вас не сделает — покупки, создание аккаунтов, безвозвратное удаление и подобные действия.
  • Главный риск — страница может содержать скрытые инструкции для Claude (prompt injection). Claude действует от вашего имени и с вашими входами на сайты, поэтому на сайтах с деньгами и личными данными не оставляйте его без присмотра.

В Claude Code

Claude Code подключается к тому же расширению. Он может проверить свою работу в браузере: открыть локальный сервер, пройти сценарий, прочитать ошибки консоли и сетевые запросы. Запуск с браузером:

Состояние и настройки — команда /chrome: проверить подключение, переподключить расширение, включить браузер по умолчанию. Нужны расширение и вход через /login. Кроме Chrome, Claude Code работает с Edge и другими браузерами на Chromium.
