Коннекторы

Коннектор (connector) подключает Claude к вашему сервису: почте, календарю, диску, таск-трекеру. Через него Claude читает ваши данные и может действовать: создать задачу, написать черновик письма. Внутри это MCP-сервер, но знать об этом не обязательно — подключение делается в пару кликов.

Для чего

  • Вопросы по своим данным — что в календаре, где нужный документ, что писал клиент.
  • Действия в сервисах — задача в Linear, сообщение в Slack, черновик письма в Gmail.
  • Сводки из нескольких мест — письма, встречи и задачи в одном ответе.
  • Живые данные в артефактах — дашборд, который подтягивает свежие цифры при каждом открытии.

Как подключить

  • 1. Откройте Customize → Connectors и нажмите + рядом с Connectors. Из чата то же самое: + → Connectors → Manage connectors.
  • 2. Выберите сервис в каталоге. В карточке видно, что он умеет и только ли читает данные или может их менять. Нажмите Connect.
  • 3. Войдите в аккаунт сервиса и разрешите доступ.
  • 4. В чате нажмите + → Connectors и включите нужные для этого разговора. Подключённый сервис Claude может взять и сам, если он подходит к вопросу.

Примеры запросов:

Свой коннектор

  • Удалённый MCP-сервер — Customize → Connectors → Add → Custom → Web, затем имя, URL сервера и способ входа. Сервер должен быть доступен из интернета: запросы к нему идут из облака Anthropic, а не с вашего компьютера. На Free можно добавить только один такой коннектор.
  • Локальное расширение — только в Claude Desktop: Settings → Extensions, там каталог расширений. Своё ставится из файла .mcpb: Advanced settings → Install Extension…. Расширение работает на вашем компьютере и может достать до локальных файлов и программ.

Что важно знать

  • Права как у вас — Claude видит в сервисе только то, что можете открыть вы сами.
  • Подключайте только то, чему доверяете — коннектор может менять данные. Свои коннекторы Anthropic не проверяет. Неиспользуемые лучше отключить.
  • Много коннекторов — если их больше десяти, в + → Connectors переключите Tool access с Auto на On demand. Тогда Claude загружает инструменты по мере надобности и не забивает ими контекст.
  • Team и Enterprise — владелец сначала добавляет коннектор для организации (Organization settings → Connectors), а потом каждый входит своим аккаунтом. Владелец же задаёт для инструментов Always allow, Needs approval или Blocked.
  • Тарифы — каталог коннекторов доступен на всех тарифах, включая Free, в браузере, Claude Desktop и мобильных приложениях.

Аналог в Claude Code. Если войти в Claude Code аккаунтом claude.ai (/login), ваши коннекторы появятся там сами: /mcp покажет их как claude.ai Gmail и т. п. Другие серверы подключаются командой claude mcp add — см. Подключение сервера.
