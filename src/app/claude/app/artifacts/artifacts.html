Claude/Приложение Claude/Artifacts

Artifacts

Артефакт (artifact) — готовый результат работы Claude, который открывается в отдельном окне рядом с чатом: документ, презентация, код, схема, дашборд или небольшое интерактивное приложение. Его можно править, открыть снова из любого чата и отправить ссылкой.

Для чего

  • Документы и презентации — отчёт, план, слайды. Правите прямо в окне и выгружаете в Word, PDF или PowerPoint.
  • Мини-приложения — калькулятор, тренажёр, викторина, трекер привычек. Работают в браузере, ничего не нужно устанавливать.
  • Наглядные данные — графики и дашборды по вашей таблице, схемы процессов.
  • Прототипы — макет экрана или лендинга, чтобы посмотреть на идею до того, как писать код.

Как включить и создать

  • 1. Откройте Settings → Capabilities и включите Cloud code execution and file creation. Без него артефакты не создаются. На Team и Enterprise переключатель у владельца: Organization settings → Capabilities.
  • 2. Попросите в чате. Claude сам оформит ответ артефактом, если результат объёмный (обычно длиннее 15 строк), самодостаточный и его, скорее всего, будут дорабатывать.
  • 3. Чтобы задать формат явно, нажмите Output в поле ввода и выберите шаблон. Или начните с вкладки Artifacts в боковой панели — там же лежат все ваши артефакты.
  • 4. Правки просите у Claude. В документах и слайдах можно править и самому, а в документе — выделить фрагмент и нажать Edit with Claude.

Что ещё умеют

  • Вызывать Claude — приложение в артефакте может само обращаться к Claude: переводчик, генератор идей, чат-бот. Каждый пользователь тратит лимиты своего тарифа, API-ключ не нужен. При первом вызове артефакт спрашивает разрешение.
  • Хранить данные — до 20 МБ текста на артефакт. Личное хранилище у каждого своё, общее одно на всех: так делают голосования и общие списки. Pro и выше.
  • Брать данные из сервисов — через коннекторы (Google Calendar, Slack, Asana и другие). Каждый сервис вы подтверждаете при первом обращении. Pro и выше.
  • Чиниться — если артефакт упал с ошибкой, нажмите Try fixing with Claude.

Как поделиться

  • По умолчанию приватно — артефакт видите только вы.
  • Ссылка — откройте артефакт → Share → в Who has access выберите, кому доступно, → скопируйте ссылку. Pro и Max: Only you, Anyone with the link или приглашение по email. Team и Enterprise: приглашённые, вся организация или все по ссылке, если владелец разрешил внешний доступ.
  • Права — Can view (смотреть), Commenter (ещё комментировать и скачивать файлы) и Can edit (править).
  • Нужен аккаунт — открыть ссылку может только тот, у кого есть аккаунт Claude.

Старые артефакты. Созданные в чате до 16 сентября 2026 года продолжают работать по-старому. У них кнопки просмотра кода, копирования и скачивания, а делятся ими через Publish: такую ссылку открывают и без аккаунта. Unpublish необратим — ссылка и сохранённые данные удаляются.

В Claude Code

  • Что это — Claude Code публикует результат сессии как живую страницу по приватной ссылке на claude.ai: разбор PR, дашборд по данным, сравнение вариантов. Страница обновляется по ходу работы.
  • Как попросить — словами, как в примере ниже. Для презентации и макета есть команды /slides и /design.
  • Где найти — /artifacts показывает ваши артефакты, Ctrl+] открывает последний. В браузере все они собраны в галерее claude.ai/code/artifacts.
  • Условия — Pro и выше, вход через /login аккаунтом claude.ai. С API-ключом артефакты не публикуются.
