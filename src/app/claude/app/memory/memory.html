Память и поиск по чатам

Две функции, чтобы не объяснять Claude одно и то же в каждом новом чате. Память — Claude сам запоминает важное о вас и вашей работе и учитывает это дальше. Поиск по чатам — Claude находит нужное в прошлых разговорах, когда вы на них ссылаетесь.

Чем отличаются

ПамятьПоиск по чатам
Что хранитКороткие темы: кто вы, над чем работаете, как вам отвечатьНичего отдельно — ищет по полному тексту прошлых чатов
Когда работаетВсегда, в каждом новом чатеКогда вы ссылаетесь на прошлое: «мы обсуждали…», «как мы тогда…»
ТарифыВсе. На Team и Enterprise владелец включает её для организации, а каждый участник — для себяPro, Max, Team, Enterprise
ПереключательGenerate memory from chatsSearch and reference chats

Для чего

  • Не повторять контекст — профессия, стек, язык и стиль ответов, текущие проекты.
  • Продолжить начатое — вернуться к плану или черновику из прошлого чата, не копируя его.
  • Найти решение — вспомнить, как уже решали похожую задачу.

Как включить

  • 1. Откройте Settings → Memory.
  • 2. Включите Generate memory from chats (память) и Search and reference chats (поиск). На Free, Pro и Max они обычно уже включены.
  • 3. Чувствительные темы по умолчанию не запоминаются. Если нужно, включите Include sensitive topics in memory. Номера документов и банковских счетов не сохраняются никогда.

Видите Memory в Settings → Capabilities, а не отдельным пунктом? Это старая версия памяти, она осталась у части организаций на Team и Enterprise. В ней память обновляется раз в сутки, а не сразу.

Как управлять

  • Прямо в чате — попросите запомнить, исправить или забыть что-то. Примеры ниже.
  • В настройках — Settings → Memory → Topics: всё, что Claude помнит, по темам. Тему можно открыть, поправить или удалить (Delete).
  • Пауза и сброс — при выключении памяти Claude предложит Pause memory (сохранить, но не использовать и не пополнять) или Reset memory (стереть всё, включая память проектов, без возможности восстановить).
  • Один чат без памяти — до первого сообщения нажмите + в поле ввода и выключите Memory.
  • Инкогнито — значок призрака справа вверху в новом чате вне проекта. Такой чат не попадает ни в историю, ни в память, и поиск его потом не найдёт.
  • Проекты — у каждого проекта своя память. Внутри него Claude видит её и общую память, но не память других проектов.

Перенос из другого ассистента

  • 1. Settings → Memory → Start import. Claude покажет готовый запрос — отправьте его прежнему ассистенту (ChatGPT, Gemini и т. п.). Тот выпишет всё, что о вас помнит.
  • 2. Вставьте ответ в окно импорта и нажмите Add to memory. Claude разложит его по темам.
  • 3. Проверьте результат в Topics. Функция экспериментальная: часть фактов может не сохраниться, особенно личные, не связанные с работой.

Обратно, для резервной копии, — попросите Claude в чате дословно выписать всё, что он помнит.
