Headless-режим

Headless-режим — Claude Code без интерфейса: claude -p "задача" выполняет задачу, печатает результат в stdout и завершается. Это тот же агент, с файлами, Bash и инструментами, только вызывается как обычная консольная утилита — из скрипта, CI, cron или другой программы. В документации он называется non-interactive mode.

Для чего

  • Pipe — разобрать лог, дифф или вывод команды и отдать ответ дальше по конвейеру.
  • Скрипты сборки и CI — ревью пул-реквеста, поиск опечаток, починка упавших тестов.
  • Пакетная работа — одна и та же правка по сотне файлов или репозиториев в цикле.
  • Вызов из другой программы — подпроцесс с JSON на выходе, из любого языка.

Запуск

  • Код выхода — 0 при успехе, иначе ненулевой: скрипт может на него опираться.
  • stdin — до 10 МБ. Что больше, сохраните в файл и укажите путь в задаче.
  • Настройки те же, что в обычной сессии: CLAUDE.md, settings.json, хуки, MCP-серверы, скиллы. Отключить их загрузку — флаг --bare, см. ниже.
  • Команды только для терминала вроде /login не работают. Скиллы и свои команды работают: напишите /имя в тексте задачи.

Разрешения

Отвечать на запросы разрешений некому, поэтому всё, что требует подтверждения, отклоняется. Нужное разрешают заранее — флагом --allowedTools или режимом:

  • --allowedTools — тот же синтаксис, что у правил в разрешениях. Пробел перед * важен: Bash(git diff *) пропустит git diff main, а Bash(git diff*) — ещё и git diff-index.
  • --permission-mode — acceptEdits разрешает правки файлов, auto отдаёт решения классификатору, dontAsk выполняет только явно разрешённое.

Формат ответа

--output-formatЧто на выходе
text (по умолчанию)Только текст ответа
jsonОдин объект: result, session_id, total_cost_usd и другие поля
stream-jsonПоток событий, по JSON в строке. Нужен ещё флаг --verbose

Если Claude не смог выдать ответ по схеме, поля structured_output не будет — проверяйте его наличие. total_cost_usd — оценка на стороне клиента, счёт может отличаться.

Режим --bare для CI

С --bare Claude Code ничего не подхватывает сам: ни CLAUDE.md, ни хуки, ни плагины, ни скиллы, ни MCP-серверы, ни автопамять. Остаются чтение и правка файлов и Bash, а всё нужное передают флагами. Запуск быстрее, и результат не зависит от того, что настроено на машине.

  • Вход — только по ключу. --bare не читает вход по подписке: нужен ANTHROPIC_API_KEY из Claude Console. Без --bare в CI можно взять токен подписки: claude setup-token выдаст его, а передают его в переменной CLAUDE_CODE_OAUTH_TOKEN.
  • Чужой репозиторий — только с --bare. Без него claude -p сразу выполнит хуки из .claude/settings.json и подключит серверы из .mcp.json: окна доверия к папке здесь нет.
  • Рекомендован для скриптов и CI. Anthropic планирует сделать его поведением -p по умолчанию.
