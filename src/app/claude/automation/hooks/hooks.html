Хуки

Хук — ваша команда, которую Claude Code сам запускает в нужный момент: перед вызовом инструмента, после правки файла, на старте сессии, когда Claude ждёт ответа. Правило из CLAUDE.md модель может забыть, а хук срабатывает всегда: его исполняет программа, а не модель.

Для чего

  • Форматирование — прогнать Prettier или линтер по каждому файлу, который правил Claude.
  • Запреты — не давать править .env и lock-файлы, блокировать опасные команды.
  • Уведомления — сообщить, что Claude ждёт разрешения или закончил работу.
  • Контекст — подложить Claude актуальные сведения: ветку, последние коммиты, правила проекта после сжатия контекста.
  • Журнал — записывать каждую команду или отправлять события в свой сервис аудита.

Как устроен

Хуки описывают в ключе hooks файла settings.json. Пример: после каждой правки файла прогнать по нему Prettier.

  • Событие (PostToolUse) — когда срабатывать.
  • matcher — фильтр внутри события. Для событий инструментов это имя инструмента: Edit|Write, Bash, mcp__github__.*. Регистр важен. Без matcher хук срабатывает на каждое событие.
  • type — что запускать; чаще всего command, команда оболочки.

Писать руками не обязательно. Опишите Claude, что нужно («после каждой правки гоняй prettier»), — он сам добавит хук в settings.json. Проверить, что хук на месте, — команда /hooks: она показывает все хуки по событиям.

Основные события

СобытиеКогда
SessionStartСтарт и возобновление сессии, после /clear и сжатия контекста. stdout команды попадает в контекст Claude
UserPromptSubmitВы отправили сообщение, Claude его ещё не прочитал. Можно добавить контекст или отклонить запрос
PreToolUseПеред вызовом инструмента. Можно запретить вызов
PermissionRequestClaude Code собирается спросить разрешение — хук может ответить за вас
PostToolUseПосле успешного вызова инструмента
NotificationClaude ждёт вашего ответа или разрешения
Stop, SubagentStopClaude или субагент закончил отвечать
PreCompact, PostCompactДо и после сжатия контекста
SessionEndСессия завершилась

Всего событий больше тридцати: смена рабочей папки, изменение файла на диске, запуск субагента, создание worktree и другие. Полный список — в справочнике по хукам.

Где хранить

ГдеДействует
~/.claude/settings.jsonВо всех ваших проектах
.claude/settings.jsonВ проекте, для всех: файл коммитится в git
.claude/settings.local.jsonВ проекте, только у вас
Управляемые настройкиВо всей организации, задаёт администратор
hooks/hooks.json плагинаПока плагин включён
Frontmatter скилла или субагентаПосле вызова скилла или пока работает субагент

Выключить все хуки разом — "disableAllHooks": true в settings.json. Хуки из управляемых настроек при этом продолжат работать, если ключ не выставлен и там.

Вход и выход команды

На stdin команда получает JSON с описанием события. Для PreToolUse перед npm test:

Ответ Claude Code понимает по коду выхода:

  • 0 — возражений нет. Для PreToolUse это не разрешение: дальше вызов идёт обычной проверкой разрешений. У SessionStart и UserPromptSubmit текст из stdout добавляется в контекст Claude.
  • 2 — заблокировать. Текст из stderr получит Claude и попробует по-другому. Не всё можно заблокировать: у SessionStart, например, код 2 только покажет stderr вам.
  • Любой другой — ошибка хука; действие продолжается, в разговоре появится предупреждение.

Для тонкого управления команда выходит с кодом 0 и печатает JSON. Так PreToolUse возвращает решение permissionDecision: deny с причиной, ask — спросить вас, allow — не спрашивать. Поля для каждого события — в справочнике.

Примеры

Защитить файлы от правки

Скрипт проверяет путь и выходит с кодом 2, если файл защищён. На macOS и Linux сделайте его исполняемым: chmod +x .claude/hooks/protect-files.sh.

$CLAUDE_PROJECT_DIR — корень проекта: путь к скрипту не сломается, если Claude перейдёт в подпапку.

Уведомление, когда Claude ждёт

  • permission_prompt — ждёт разрешения; idle_prompt — ответил и около минуты ждёт вашего сообщения. Пустой matcher — все уведомления.
  • Команда в примере для Linux. На macOS — osascript -e 'display notification "Нужен ваш ответ" with title "Claude Code"', на Windows — вызов powershell.exe с окном сообщения.
  • Где хранить — в ~/.claude/settings.json: уведомления нужны во всех проектах.

Безопасность и ограничения

  • Хук запускается с вашими правами и без вопросов. Прежде чем работать в чужом репозитории, посмотрите хуки в его .claude/settings.json.
  • Запрет хука сильнее режима. deny из PreToolUse блокирует вызов даже в bypassPermissions. Обратное не работает: allow хука не отменяет deny-правила из настроек.
  • PostToolUse ничего не отменит — инструмент уже отработал.
  • Matcher Edit|Write видит не все правки: Claude может изменить файл и через Bash. Если нужен каждый изменённый файл, добавьте хук на Stop, который смотрит git status.
  • Таймаут команды по умолчанию — 10 минут, меняется полем timeout в секундах.

Вне терминала. Вкладка Code в Claude Desktop — это тот же Claude Code: хуки из settings.json работают и там. В Agent SDK хуки задают обычными функциями в коде. В чате claude.ai своих хуков нет, а Cowork выполняет хуки из плагинов.
